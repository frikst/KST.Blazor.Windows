# Changelog

## [1.0.0] - 2026-08-27
### Added
- Migrated to .NET 10
- Possibility to get window position/size
- Possibility to move/resize window programmatically
- Support for the new Window Management API
- Maximization support on Chrome 155 and newer
- Blazor Server connection problems are now shown in the opened windows too

### Fixed
- Deprecated unload event is no longer used
- Many other bug fixes

## [1.0.0-pre20211216] - 2021-12-16
### Added
- Maximized and centered window positions can be used as InitialPosition
- Window can be closed programatically

### Fixed
- Correct way to request window-placement permission
- Blazor element reference is working correctly in non-main windows

## [1.0.0-pre20211215] - 2021-12-15
Initial prerelease
